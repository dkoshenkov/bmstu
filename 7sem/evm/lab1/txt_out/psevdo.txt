
Исходные данные:
- Массив целых чисел `_x` из 8 элементов:
  [1, 2, 3, 4, 5, 6, 7, 8]
- `len = 8`        — количество элементов массива
- `enroll = 4`     — сколько элементов обрабатывается за одну итерацию цикла
- `elem_sz = 4`    — размер одного элемента (в байтах)

Обозначения:
- `x1`  — указатель на текущую позицию в массиве
- `x20` — адрес, на котором нужно остановиться (адрес, следующий за последним обрабатываемым блоком)
- `x31` — аккумулятор суммы (результат)

Псевдокод:

```
int _x[8] = {1,2,3,4,5,6,7,8};

void _start() {
    int *x1;      // указатель на текущий элемент массива
    int *x20;     // адрес, на котором нужно остановиться
    int x31 = 0;  // аккумулятор суммы

    x1  = &_x[0];             // адрес первого элемента массива
    x20 = x1 + len;           // адрес элемента, следующего за последним

    do {
        // считаем сумму четырёх подряд идущих элементов
        x31 = x31 + x1[0];    // !
        x31 = x31 + x1[1];
        x31 = x31 + x1[2];
        x31 = x31 + x1[3];

        x1 = x1 + enroll;     // сдвигаем указатель на следующий блок из 4-х элементов
    } while (x1 != x20);      // пока не дошли до конца массива

    x31 = x31 + 1;            // после цикла увеличиваем сумму на 1

    while (1) {
        // бесконечный цикл
    }
}
```

Ручной расчет значения регистра `x31`:

1. В начале работы программы `x31 = 0`.
2. В массиве `_x` лежат значения: 1, 2, 3, 4, 5, 6, 7, 8.
3. В цикле последовательно суммируются **все 8 элементов** по 4 за итерацию:
   - Первая итерация (`x1` указывает на `_x[0]`..`_x[3]`):
     - `x31 = 0 + 1 + 2 + 3 + 4 = 10`
   - Вторая итерация (`x1` указывает на `_x[4]`..`_x[7]`):
     - `x31 = 10 + 5 + 6 + 7 + 8 = 36`
4. После выхода из цикла выполняется `x31 = x31 + 1`, поэтому:
   - `x31 = 36 + 1 = 37`

Итог:
- В момент окончания программы (перед входом в бесконечный цикл) в регистре `x31` должно быть значение **37**.
